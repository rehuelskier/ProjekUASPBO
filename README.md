Deskripsi Project Kami membuat project game bergenre Semi Horror, Adventure. Game ini memiliki berbagai macam puzzle menantang yang harus diselesaikan untuk menuju level berikutnya, kita bermain sebagai player yang sedang berburu hantu sekaligus mencari harta karun.

Fitur utama • Sistem movement player (atas, bawah, kiri, kanan). • Musuh berupa Ghost/Zombie yang akan mengejar atau menghalangi pemain. • Coin yang dapat dikumpulkan untuk menambah skor. • Rock (batu menggelinding) sebagai rintangan dinamis yang dapat membahayakan pemain. • Trap yang mengurangi nyawa pemain saat terkena. • Sistem nyawa (Lives). • Checkpoint yang menyimpan progres pemain sehingga ketika mati dapat kembali ke checkpoint terakhir. • Key Door yang mengharuskan pemain mencari kunci untuk membuka area tertentu. • Switch dan Door yang berfungsi sebagai puzzle untuk membuka jalan menuju area berikutnya. • Treasure (Berupa key) yang dapat diperoleh setelah player menyentuhnya. • Sistem invincible sementara setelah terkena serangan untuk mencegah damage berulang dalam waktu singkat. • Exit Door sebagai tujuan akhir level. • Sistem beberapa level dengan tingkat kesulitan yang meningkat.

Cara menjalankan project • Pastikan Python telah terinstal. • Install library pygame dengan perintah: pip install pygame • Buat folder baru • Buka folder project melalui pycharm • Masukkan kode program • Jalankan file utama: bagian (main.py) • Game akan terbuka dan siap dimainkan.

Penjelasan implementasi OOP Game menggunakan konsep Object Oriented Programming (OOP) seperti inheritance, encapsulation, abstraction, dan polymorphism untuk mengelola berbagai objek dalam permainan seperti Player, Ghost(Zombie), Wall, Coin, Rock, Trap, Door, Switch, dan Treasure.
